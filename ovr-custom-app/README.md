# VRChat Clipper OVR Toolkit app

## Install

1. Copy this whole folder into `%OVRToolkitInstallDir%/LocalCustomApps/VRChatClipper/`.
2. Restart OVR Toolkit.
3. Open Edit Mode.
4. Find the VRChat Clipper tile.
5. Pin it to your wrist.

The clipper server must be running with `python -m vrchat_clipper`. The wrist trigger calls `http://127.0.0.1:8765/api/clip`, which matches the default server config.
